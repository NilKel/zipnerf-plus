# Multi-Resolution Confidence Field with Downsampling

This document describes the improved multi-resolution confidence field implementation that uses **downsampling from a single high-resolution grid** rather than independent parameters at each resolution.

## 🎯 **Key Improvement**

**Before**: Multiple independent confidence grids at different resolutions
- ❌ Inconsistent occupancy representation across scales
- ❌ More parameters to optimize
- ❌ No guarantee of coherent multi-scale structure

**After**: Single high-resolution grid with downsampled lower resolutions  
- ✅ Consistent occupancy across all scales
- ✅ Fewer parameters (only high-res grid optimized)
- ✅ Coherent multi-scale representation

## 🏗️ **Architecture**

### Single Learnable Grid
- Only the **highest resolution grid** is a learnable parameter
- All lower resolutions are generated by **adaptive average pooling**
- Gradients only computed for the base grid

### Downsampling Process
```python
# Example: Base grid 64³ → downsampled to 32³, 16³
base_conf = torch.sigmoid(c_grid)  # (64, 64, 64)
downsampled_32 = F.adaptive_avg_pool3d(base_conf, (32, 32, 32))
downsampled_16 = F.adaptive_avg_pool3d(base_conf, (16, 16, 16))
```

### Multi-Scale Querying
- Sample from all resolution levels
- Combine using MLP or sum
- Gradients from base grid (consistent across scales)

## ⚙️ **Configuration**

### Multi-Resolution Mode
```python
config.confidence_grid_resolutions = [(16,16,16), (32,32,32), (64,64,64)]
config.confidence_combination_method = "mlp"  # or "sum"
config.confidence_mlp_hidden_dim = 32
config.confidence_mlp_num_layers = 2
```

### Single-Resolution Mode (Default)
```python
config.confidence_grid_resolutions = None  # Uses single resolution
config.confidence_grid_resolution = (128, 128, 128)
```

## 📊 **Benefits**

### 1. Parameter Efficiency
- **Before**: 16³ + 32³ + 64³ = 4,096 + 32,768 + 262,144 = **299,008 parameters**
- **After**: 64³ only = **262,144 parameters** (12% reduction)

### 2. Consistency
- Lower resolutions are **exact downsampled versions** of high-res
- No training inconsistencies between scales
- Coherent occupancy representation

### 3. Training Stability
- Single optimization target (base grid)
- No conflicting gradients between resolution levels
- Simplified loss computation

## 🔧 **Implementation Details**

### Grid Generation
```python
def _generate_downsampled_grids(self):
    """Generate downsampled versions using adaptive pooling."""
    base_conf = torch.sigmoid(self.c_grid)  # High-res grid
    
    for target_res in self.resolutions:
        if target_res == self.base_resolution:
            # Store base grid directly
            self._cached_downsampled_grids[i] = base_conf
        else:
            # Downsample using adaptive pooling
            downsampled = F.adaptive_avg_pool3d(base_conf, target_res)
            self._cached_downsampled_grids[i] = downsampled
```

### Gradient Computation
- Only computed for base grid: `self.grad_c_grid`
- All resolution levels use the same gradient field
- Cache invalidated when base grid changes

### Querying Process
1. Generate downsampled grids if cache invalid
2. Sample from all resolution levels  
3. Combine using chosen method (MLP/sum)
4. Use base grid gradients for all levels

## 🧪 **Usage Examples**

### Basic Multi-Resolution
```python
from internal.field import ConfidenceField

# Create multi-resolution field
conf_field = ConfidenceField(
    resolutions=[(16,16,16), (32,32,32), (64,64,64)],
    combination_method="sum",
    device="cuda"
)

# Only base grid parameters are optimized
total_params = sum(p.numel() for p in conf_field.parameters() if p.requires_grad)
print(f"Parameters: {total_params:,}")  # Only 64³ = 262,144

# Compute gradients (only for base grid)
conf_field.compute_gradient()

# Query points (samples from all resolutions)
points = torch.rand(1000, 3) * 2 - 1  # [-1, 1] range
confidence, gradients = conf_field.query(points)
```

### Accessing Individual Resolutions
```python
# Get all downsampled grids
all_grids = conf_field.get_confidence()  # List of tensors
print([grid.shape for grid in all_grids])  # [(16,16,16), (32,32,32), (64,64,64)]

# Get specific resolution
grid_32 = conf_field.get_confidence(grid_index=1)  # 32³ grid
```

## 🔄 **Migration from Old System**

### Automatic Detection
The system automatically detects which mode to use:
- `confidence_grid_resolutions = None` → Single resolution
- `confidence_grid_resolutions = [...]` → Multi-resolution with downsampling

### Backward Compatibility
- Single-resolution mode unchanged
- All existing configs work without modification
- Only new multi-resolution configs use downsampling

## 📈 **Performance**

### Memory Usage
- **Reduced parameter count**: Only base grid stored
- **Cached downsampling**: Generated on-demand, cached until base grid changes
- **Efficient querying**: No redundant gradient computations

### Training Speed
- **Faster gradient computation**: Single grid instead of multiple
- **Consistent optimization**: No conflicting parameter updates
- **Stable convergence**: Coherent multi-scale representation

## 🔍 **Comparison Summary**

| Aspect | Old Multi-Res | New Downsampled |
|--------|---------------|-----------------|
| Parameters | All grids | Base grid only |
| Consistency | Independent | Downsampled |
| Memory | Higher | Lower |
| Training | Complex | Simplified |
| Occupancy | May differ | Coherent |

## 🎉 **Conclusion**

The new downsampling-based approach provides:
- ✅ **Consistent** multi-scale occupancy representation
- ✅ **Efficient** parameter usage (only base grid optimized)  
- ✅ **Coherent** structure across resolution levels
- ✅ **Backward compatible** with existing single-resolution setups
- ✅ **Simplified** training (single optimization target)

This makes much more sense for confidence/occupancy fields where lower resolutions should be coarser versions of the same underlying structure, not independent representations!
